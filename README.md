Designed and implemented CNN and Vision Transformer (ViT) models for fish species classification, achieving 89% and 95% accuracy, respectively, and demonstrating advanced deep learning capabilities in marine research. Preprocessed datasets using OpenCV (noise reduction, resizing, normalization) with augmentation techniques (rotation, flipping, color jittering), and optimized model robustness with cross-validation, hyperparameter tuning, and regularization. Evaluated models using precision, recall, F1-score, and confusion matrices, ensuring scalability and reliability for real-world applications through standardized data pipelines and advanced training strategies.
